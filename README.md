# LabelFlow Studio

LabelFlow Studio — это WPF-приложение для автоматизации печати торцевых этикеток и сопроводительных листов в логистической системе склада.

Система обрабатывает идентификатор коробки, получает связанные данные из базы Oracle и автоматически формирует печатные документы.

---

## Основные возможности

### Обработка данных коробки
Получение полной информации о коробке и заказе из Oracle по уникальному идентификатору TENAM.

### Два режима работы

**Ручной режим**
- Ввод TENAM вручную
- Просмотр данных
- Запуск печати

**Автоматический режим**
- Приём данных со сканера через COM-порт
- Автоматическая обработка и печать без участия пользователя

---

### Редактор HTML-шаблонов

- Встроенный редактор на базе Monaco Editor
- Live-предпросмотр через WebView2
- Раздельный режим: код + предпросмотр
- Интеллектуальное обновление шаблонов

## Архитектура

Проект построен по слоистой архитектуре с разделением ответственности:

- **Core** — доменные модели и абстракции
- **Data** — работа с Oracle через EF Core
- **Application** — бизнес-логика и сервисы
- **Devices** — интеграция с оборудованием
- **Printing** — генерация и печать документов
- **Templates** — управление HTML-шаблонами
- **Desktop** — WPF UI
- **Tests** — модульные тесты

## Запуск проекта

### Требования

- .NET 6 SDK
- WebView2 Runtime

### Настройка

1. Клонировать репозиторий:

git clone https://github.com/codeislive63/LabelFlowStudioProject.git
cd LabelFlowStudioProject

2. Настроить строку подключения к Oracle через User Secrets:

dotnet user-secrets set "ConnectionStrings:Oracle" "ваша_строка_подключения"

3. Собрать решение
4. Запустить проект `LabelFlowStudio.Desktop`

При первом запуске появится мастер настройки принтеров.
